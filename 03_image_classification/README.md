# Классификация изображений

Фреймворк: **Keras Applications (TensorFlow)**. Модель: [`EfficientNetB0`](https://keras.io/api/applications/efficientnet/) с весами ImageNet, для сравнения [`ResNet50`](https://keras.io/api/applications/resnet/).

## Техническое задание

- **Цель:** определить, что изображено на фотографии, выбрав один из 1000 классов ImageNet (животные, предметы, транспорт, здания и т. д.).
- **Вход:** файл с картинкой (jpg, png и другие форматы, которые читает Pillow) любого размера. Картинка уменьшается по короткой стороне, и из центра вырезается квадрат 224×224.
- **Выход:** 5 самых вероятных классов: WNID (идентификатор класса ImageNet), английское название и вероятность от 0 до 1.
- **Ограничения:** работа на CPU без видеокарты, ответ на одну картинку быстрее 100 мс, модель меньше 50 МБ.
- **Критерии качества:** top-1 и top-5 accuracy на фотографиях, которых модель не видела при обучении. Для EfficientNetB0 top-1 не ниже 75%.

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

При первом запуске веса скачиваются в `~/.keras/models`: EfficientNetB0 весит ~21 МБ, ResNet50 ~100 МБ.

## Запуск

```bash
python classify.py examples/dog.jpg examples/parachute.jpg
python classify.py examples/church.jpg --model resnet50 --top 3
```

Из кода:

```python
from classify import classify
classify("examples/dog.jpg", top=1)  # [{'wnid': 'n02102040', 'label': 'English_springer', 'score': 0.725}]
```

## Оценка качества

Набор: [Imagenette](https://github.com/fastai/imagenette) (версия 320 px). Это подмножество ImageNet из 10 классов, которые легко отличить друг от друга. Скачать его (~340 МБ) в `data/`:

```bash
mkdir -p data
curl -L https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-320.tgz | tar -xz -C data
```

```bash
python evaluate.py                       # обе модели, 500 картинок из validation ImageNet
python evaluate.py --subset seen         # 3791 картинка из train ImageNet, для сравнения
python evaluate.py --per-class 10 --models efficientnetb0
```

Почти все картинки Imagenette, в том числе из `val/`, взяты из **обучающей** выборки ImageNet: это видно по именам файлов `n03028079_28432.JPEG`. Модели учились именно на них, поэтому оценка по ним завышена. Модель не видела только файлы `ILSVRC2012_val_*` из `train/` и `val/`. Их ровно 500, по 50 на класс, то есть это вся валидационная часть ImageNet для этих 10 классов. `evaluate.py` по умолчанию считает метрики на них.

Метрики считаются по всем 1000 классам ImageNet, а не по 10, то есть ответ «замок» на фото церкви считается ошибкой.

| Модель | Параметров | top-1 | top-5 | Мс на картинку | Картинок/с батчами |
|--------|-----------:|------:|------:|---------------:|-------------------:|
| EfficientNetB0 | 5.3 M | 0.780 | 0.956 | **50** | **27.7** |
| ResNet50 | 25.6 M | **0.788** | **0.958** | 86 | 14.9 |

- **top-1 accuracy** — доля картинок, у которых самый вероятный класс правильный.
- **top-5 accuracy** — доля картинок, у которых правильный класс есть среди 5 самых вероятных. Метрика важна для ImageNet, где многие классы почти неотличимы (породы собак, церковь / монастырь).

Время на картинку включает чтение файла и предобработку, в батче 32 картинки. Замеры на CPU Intel i3-7100, время загрузки модели не учитывается. Для сравнения, по документации Keras на всём ImageNet top-1 у EfficientNetB0 0.771, у ResNet50 0.749.

Top-1 по классам:

| Класс | EfficientNetB0 | ResNet50 |
|-------|---------------:|---------:|
| tench (линь) | 0.98 | 0.96 |
| English springer | 0.90 | 0.90 |
| cassette player | 0.34 | 0.28 |
| chain saw | 0.82 | 0.76 |
| church | 0.36 | 0.58 |
| French horn | 0.80 | 0.78 |
| garbage truck | 0.98 | 0.98 |
| gas pump | 0.82 | 0.86 |
| golf ball | 0.90 | 0.84 |
| parachute | 0.90 | 0.94 |

Точность у моделей почти одинаковая, но EfficientNetB0 в 5 раз меньше и в 1.7–1.9 раза быстрее, поэтому основной выбрана она. Хуже всего распознаются кассетный плеер и церковь, и почти все ошибки по ним приходятся на соседние классы ImageNet. Кассетный плеер EfficientNetB0 чаще называет магнитофоном (`tape_player`, 22 из 50), чем правильно (17), иногда CD-плеером или кассетой. Церковь путает с монастырём, а снимки изнутри со сводом (`vault`), колокольней и алтарём. Такие ошибки не спасают top-1, но правильный класс обычно попадает в первую пятёрку, поэтому top-5 у обеих моделей около 0.96.

Если оценивать на 3791 картинке из train ImageNet (`--subset seen`), top-1 у EfficientNetB0 получается 0.821, у ResNet50 0.888, на 4 и 10 пунктов выше, чем на новых картинках. Видимо, ResNet50 сильнее запомнила обучающую выборку.
