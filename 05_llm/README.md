# Локальная LLM

Движок: **Ollama** (поверх llama.cpp). Модель: [`qwen3.5:4b`](https://ollama.com/library/qwen3.5) в квантовании Q4_K_M, для сравнения `qwen3.5:0.8b` и `qwen3.5:2b`.

Это пятый пункт задания: развернуть открытую LLM локально, без сторонних серверов. Та же Ollama и те же модели потом используются в С1СЗ4, там они сравниваются на задачах агента (tool calling, извлечение фактов, выдумки), здесь только запуск и базовые замеры.

## Техническое задание

- **Цель:** отвечать на вопросы и вести диалог на русском языке на локальной машине без видеокарты.
- **Вход:** текст вопроса или история диалога (список сообщений system / user / assistant).
- **Выход:** текст ответа и статистика: число токенов промпта и ответа, скорость обработки и генерации, время загрузки.
- **Ограничения:** только открытые веса, работа на CPU (i3-7100, 2 ядра) и 16 ГБ памяти, модель не больше 4–5 ГБ на диске, ответ на короткий вопрос не дольше минуты.
- **Критерии качества:** модель отвечает по делу на простые вопросы (проверка в `bench.py`: не меньше 7 из 8), генерация не медленнее 5 токенов в секунду.

## Установка

```bash
# Arch: sudo pacman -S ollama; другие системы: https://ollama.com/download
ollama serve &                       # обычно уже запущена как служба
ollama pull qwen3.5:4b               # 3.3 ГБ
ollama pull qwen3.5:0.8b qwen3.5:2b  # для сравнения, около 1 и 2 ГБ
```

Python-пакеты не нужны: скрипты ходят в HTTP API Ollama через `urllib`.

## Запуск

```bash
python chat.py "Объясни, что такое переобучение, в двух предложениях"
python chat.py --model qwen3.5:0.8b -v       # -v: токены и скорость
python chat.py                               # диалог с историей, /exit для выхода
```

Из кода:

```python
from chat import chat
answer, stats = chat([{"role": "user", "content": "Столица Франции?"}])
```

## Оценка

```bash
python bench.py                                  # qwen3.5:0.8b, 2b, 4b
python bench.py --models qwen3.5:4b gemma4:e2b
```

Для каждой модели: время загрузки в память, память по `ollama ps`, скорость обработки длинного промпта (около 600 токенов) и генерации, медианное время ответа, доля верных ответов на 8 простых вопросах (столица, арифметика, перевод, факт). Последнее не бенчмарк вроде MMLU, а проверка, что модель вообще отвечает по делу.

Замеры ниже сделаны на том же железе скриптом сравнения из С1СЗ4 (`evals/compare_llms.py` в [movie-agents](https://github.com/sstegss/movie-agents), таблица `evals/results/llm_comparison.md`): скорость из счётчиков Ollama, память из `ollama ps`. Перемерить здесь: `python bench.py`.

| Модель | Параметров | Квантование | На диске | Загрузка, с | Промпт, ток/с | Генерация, ток/с |
|--------|-----------:|-------------|---------:|------------:|--------------:|-----------------:|
| qwen3.5:0.8b | 0.75 млрд | Q8_0 | ~1 ГБ | 7.8 | 81 | 14.7 |
| qwen3.5:2b | 1.9 млрд | Q8_0 | ~2 ГБ | 13.1 | 35 | 9.6 |
| qwen3.5:4b | 4.2 млрд | Q4_K_M | 3.3 ГБ | 11.6 | 22 | 6.4 |

Правильных ответов на 8 вопросов (`python bench.py`, прогон 11 ноября 2026; от железа это не зависит):

| Модель | Верно из 8 | Где ошиблась |
|--------|-----------:|--------------|
| qwen3.5:0.8b | 5 | 17 × 23 = «501», автор «Войны и мира» «Пушкин», самая большая планета «Земля» |
| qwen3.5:2b | 8 | нигде |
| qwen3.5:4b | 8 | нигде |

- **Промпт, ток/с**: сколько токенов входа модель обрабатывает в секунду. На CPU это главное ограничение: промпт на 1500 токенов у 4b занимает около минуты до первого слова ответа.
- **Генерация, ток/с**: скорость самого ответа. Ответ на 100 токенов у 4b идёт 15 секунд, у 0.8b 7.
- **Загрузка**: веса читаются с диска при первом запросе, потом модель остаётся в памяти (`keep_alive`, по умолчанию 5 минут).

Что видно: модель в 5 раз больше отвечает в 2.3 раза медленнее и обрабатывает промпт в 3.7 раза медленнее, зато заметно реже ошибается (в С1СЗ4 qwen3.5:0.8b в половине случаев признавала выдуманный фильм настоящим, 4b ни разу). Для чата на этом процессоре 4b на границе терпимого, 2b разумный компромисс, 0.8b годится только для простых реплик.
