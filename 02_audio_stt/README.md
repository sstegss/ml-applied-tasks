# Распознавание речи (speech-to-text)

Фреймворк: **Hugging Face transformers**. Модель: [`openai/whisper-small`](https://huggingface.co/openai/whisper-small), для сравнения [`openai/whisper-tiny`](https://huggingface.co/openai/whisper-tiny).

## Техническое задание

- **Цель:** перевести русскую речь из аудиофайла в текст.
- **Вход:** аудиофайл (wav, mp3, flac и другие форматы, которые читает ffmpeg) или массив отсчётов с частотой дискретизации. Записи длиннее 30 секунд режутся на куски автоматически.
- **Выход:** распознанный текст с пунктуацией и заглавными буквами.
- **Ограничения:** работа на CPU без видеокарты. Обработка не должна быть заметно дольше самой записи, то есть RTF около 1 или меньше.
- **Критерии качества:** WER и CER на размеченных русских записях, которых модель не видела. Для whisper-small WER не выше 15%.

## Установка

Нужен `ffmpeg` в системе (Arch: `sudo pacman -S --noconfirm ffmpeg`).

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

При первом запуске модель скачивается в `~/.cache/huggingface`: whisper-small весит ~1 ГБ, tiny ~150 МБ.

## Запуск

```bash
python transcribe.py examples/sample.wav
python transcribe.py examples/sample.wav --model openai/whisper-tiny
```

Из кода:

```python
from transcribe import transcribe
transcribe("examples/sample.wav")
```

## Пример

Запись `examples/sample.wav` взята из тестовой части FLEURS, длина 11.5 с.

```
examples/sample.wav: Мадагаскар намного больше других и является самобытным континентом в том, что касается дикой природы.
```

## Оценка качества

```bash
python evaluate.py              # tiny и small, 50 записей
python evaluate.py -n 100 --models openai/whisper-small
```

Набор: первые 50 записей тестовой части [FLEURS](https://huggingface.co/datasets/google/fleurs) `ru_ru`, 10.4 минуты аудио, в среднем 12.4 с на запись. Это прочитанные вслух предложения из Википедии с эталонной расшифровкой.

Перед сравнением ответ модели приводится к виду эталона: нижний регистр, ё → е, без знаков препинания.

| Модель | Параметров | WER | CER | RTF | Время на запись |
|--------|-----------:|----:|----:|----:|----------------:|
| whisper-tiny | 39 M | 0.296 | 0.089 | 0.26 | 3.2 с |
| whisper-small | 244 M | **0.096** | **0.025** | 1.19 | 14.8 с |

- **WER** (word error rate) — доля ошибочных слов: замены, пропуски и вставки, делённые на число слов в эталоне.
- **CER** — то же самое, но по символам. Эта метрика мягче к ошибкам в окончаниях, а в русском их много.
- **RTF** (real-time factor) — время обработки, делённое на длительность аудио. Значение меньше 1 значит, что запись обрабатывается быстрее, чем звучит.

Замеры на CPU Intel i3-7100, по одной записи, время загрузки модели не учитывается.

whisper-small ошибается примерно в каждом десятом слове, и чаще всего это одна буква или окончание: «передов» вместо «периодов», «арестотеля» вместо «аристотеля». Tiny работает в 4.5 раза быстрее, но ошибок у неё втрое больше. Ещё она часто обрывает распознавание на середине фразы, ставит точку и пропускает остаток записи. На CPU small работает чуть медленнее реального времени, а tiny примерно в 4 раза быстрее.
