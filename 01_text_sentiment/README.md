# Тональность русских текстов

Фреймворк: **Hugging Face transformers**. Модель: [`seara/rubert-tiny2-russian-sentiment`](https://huggingface.co/seara/rubert-tiny2-russian-sentiment).

## Техническое задание

- **Цель:** определить эмоциональную окраску короткого русского текста (отзыв, комментарий, пост).
- **Вход:** строка на русском языке. Длинные тексты обрезаются до 512 токенов.
- **Выход:** метка `positive`, `neutral` или `negative` и её вероятность `score` от 0 до 1.
- **Ограничения:** работа на CPU без видеокарты, ответ на один текст быстрее 50 мс, модель меньше 200 МБ. Функция `predict` потом будет использоваться в API на FastAPI.
- **Критерии качества:** accuracy и macro-F1 на размеченном наборе, который модель не видела при обучении; macro-F1 не ниже 0.6.

## Установка

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

При первом запуске модель (~120 МБ) скачивается в `~/.cache/huggingface`.

## Запуск

```bash
python sentiment.py "Отличный телефон" "собака идет"
```

Из кода:

```python
from sentiment import predict
predict("Отличный телефон")  # {'label': 'positive', 'score': 0.9937}
```

## Пример

```
positive 0.99  Отличный телефон
neutral  0.82  собака идет
neutral  0.47  ну спасибо что привезли мою пиццу всего за 3 часа
```

Последний пример — сарказм: модель его не распознаёт и сомневается (вероятность всего 0.47).

## Оценка качества

```bash
python evaluate.py
```

Набор: тестовая часть [RuSentiTweet](https://huggingface.co/datasets/psytechlab/RuSentiTweet), русские твиты с ручной разметкой. В обучающих данных модели его не было. Оставлены только метки positive / neutral / negative: 2211 примеров (483 / 1068 / 660). Метки `skip` и `speech` отброшены, у модели их нет.

| Метрика | Значение |
|---------|----------|
| Accuracy | 0.649 |
| Macro-F1 | 0.617 |
| F1 positive / neutral / negative | 0.573 / 0.714 / 0.564 |
| Скорость, батчи по 32 | ~420 текстов/с |
| Скорость, по одному тексту | ~8 мс |

Замеры на CPU Intel i3-7100.

Матрица ошибок (строки — истина, столбцы — предсказание):

|          | positive | neutral | negative |
|----------|---------:|--------:|---------:|
| positive | 245 | 216 | 22 |
| neutral  | 75 | 876 | 117 |
| negative | 52 | 294 | 314 |

Модель редко путает positive и negative между собой. Основная ошибка в другом: эмоциональные твиты она часто относит к нейтральным. На своём тестовом наборе авторы модели получили macro-F1 0.75. На твитах результат ниже: в них сленг, опечатки, ссылки и ирония, а модель обучалась в основном на отзывах и новостях.
